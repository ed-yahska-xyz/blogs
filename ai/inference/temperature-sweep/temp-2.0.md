## What to expect

This is where generation can visibly degrade: strange word choices, run-on constructions, tonal lurches, possible format breakage, and the highest hallucination risk of the sweep — errors compound token by token. One caveat worth testing rather than assuming: a strongly-conditioned task (detailed digest, strict format) concentrates so much probability mass on a narrow set of continuations that models sometimes survive T=2.0 better than folklore predicts. Whether this run collapses or merely gets weird is exactly what the experiment is for.
